# Code de conduite

Ce projet s'engage à offrir un espace d'échange respectueux et bienveillant à toutes les
personnes qui y participent, quel que soit leur niveau, leur identité ou leur origine.

## Nos engagements

Nous nous engageons à :

- être patient et courtois dans les discussions, issues et pull requests ;
- critiquer les idées, pas les personnes ;
- accueillir les débutant·e·s et les questions « basiques » sans condescendance ;
- respecter les divergences d'opinion avec des arguments, pas des attaques.

## Comportements inacceptables

- Insultes, moqueries, commentaires dégradants ou harcèlement ;
- Contenu sexuel ou discriminatoire, discours de haine ;
- Publication d'informations personnelles d'autrui (doxxing) ;
- Toute forme de spam ou de promotion non sollicitée.

## Application

Les mainteneur·rice·s peuvent retirer, modifier ou rejeter tout contenu contraire à ce code
de conduite, et bannir les personnes qui le enfreignent de façon répétée.

Pour signaler un comportement problématique, ouvrez une issue en privé ou contactez le
mainteneur via le profil GitHub du dépôt. Les signalements sont traités avec confidentialité.

Ce code est inspiré du [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1.
