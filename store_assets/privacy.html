Politique de confidentialité (FR)

KidoLock est une application de contrôle parental local : elle prête la tablette à un enfant pour un temps limité, n'autorise que les applications choisies par le parent et affiche des avertissements progressifs avant la fin de la session.

  • Aucun compte, aucune inscription.
  • Aucune donnée personnelle collectée, ni celle des parents ni celle des enfants.
  • Aucune transmission : l'application ne contient aucun SDK tiers, aucune publicité, aucun analytique, aucun traqueur. Elle fonctionne entièrement hors-ligne.
  • Stockage local uniquement : préférences (code PIN, applications autorisées, durée, langue) et état de session sont conservés sur l'appareil via le stockage privé Android, jamais envoyés.
  • Service d'accessibilité : utilisé uniquement, pendant une session active, pour détecter l'application au premier plan et appliquer le temps de jeu. Il est inactif hors session et aucune information n'est lue, conservée ou partagée au-delà de cette détection.
  • Pas de sauvegarde cloud : la sauvegarde Android est désactivée (allowBackup=false).

Pour toute question : contactez le développeur via la page du projet.

Privacy Policy (EN)

KidoLock is a local parental-control app: it lends the tablet to a child for a limited time, allows only the apps chosen by the parent and shows progressive warnings before the session ends.

  • No account, no sign-up.
  • No personal data collected, from parents or children.
  • Nothing is transmitted: the app contains no third-party SDK, no ads, no analytics, no trackers. It works fully offline.
  • Local storage only: preferences (PIN, allowed apps, duration, language) and session state are kept on the device via private Android storage and never sent.
  • Accessibility service: used only during an active session to detect the foreground app and enforce play time. It is inactive outside sessions and no information is read, kept or shared beyond that detection.
  • No cloud backup: Android backup is disabled (allowBackup=false).

For any question: contact the developer via the project page.
